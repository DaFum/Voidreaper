## 2026-07-26 - Tooltips for icon-only buttons
**Learning:** When adding `aria-label` to icon-only buttons for screen readers, sighted users can also benefit from this context. Replicating the `aria-label` text in a standard HTML `title` attribute provides a native hover tooltip, enhancing accessibility and intuitiveness for all users without requiring custom tooltip components.
**Action:** Always complement `aria-label` attributes on icon-only buttons with `title` attributes.
